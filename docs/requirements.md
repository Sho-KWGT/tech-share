# TechShare 要件定義メモ

## 1. 機能一覧（6つ）
1. **記事一覧表示機能**: 投稿された技術記事をカード形式の一覧で確認できる。
2. **記事詳細・Markdownレンダリング機能**: 記事を選択して詳細ページを表示し、本文のMarkdown（見出しやリストなど）を整形して表示する。
3. **記事作成機能**: タイトル、投稿者、本文を入力して新しい技術記事を投稿し、プレビューを確認しながら作成できる。
4. **記事編集機能**: 既存の記事の内容を編集・更新できる（更新後も作成日が変わらない仕様）。
5. **記事削除機能**: 確認ダイアログを経由して、不要な記事を削除できる。
6. **検索・認証管理機能**: キーワードによる本文・タイトルの横断検索（カスタムフック利用）と、Context APIによるログイン状態に応じたアクセス制御（編集・削除ボタンの切り替えや `/create` の保護）。

## 2. 記事のデータ項目（5つ）
データベース（`db.json` 等）で管理している記事データの基本項目です。
1. `id`: 記事を一意に識別する識別子（数値または文字列）
2. `title`: 記事のタイトル
3. `content`: 記事の本文（Markdown形式で記述）
4. `author`: 記事の投稿者名
5. `createdAt`: 記事の作成日時（YYYY-MM-DD形式など）

## 3. APIエンドポイント案（5本）
バックエンド（JSON Server等）で設計・利用しているルーティングです。
1. `GET /articles`: すべての記事データを取得する（一覧表示用）
2. `GET /articles/:id`: 指定したIDの記事データを1件取得する（詳細表示用）
3. `POST /articles`: 新規の記事データを登録する（記事作成用）
4. `PUT /articles/:id` または `PATCH /articles/:id`: 指定したIDの記事データを更新する（記事編集用）
5. `DELETE /articles/:id`: 指定したIDの記事データを削除する（記事削除用）
